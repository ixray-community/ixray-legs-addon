# IX-Ray Legs Addon

This addon adds legs for the protagonist. This addon adds legs for the protagonist. The legs are for original outfits only. Supported only on IX-Ray Platform.

## Requirements

As we previously promised we are releasing the leg addon

Installation:

1. Install the original Stalker Call of Pripyat 1.6.02
2. Install the current version of IX-Ray
3. In the root of the game create a folder `ixr_addons`
4. Extract the archive into the `ixr_addons` folder
5. Start the game and enjoy!

Link to the [current IX-Ray release](https://github.com/ixray-team/ixray-1.6-stcop/releases/latest)
